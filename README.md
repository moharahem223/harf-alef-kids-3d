# 🧸 أبطال الحروف — حرف الألف بالحركات الثلاث (أَ · أُ · إِ)
سلسلة رسوم متحركة ثلاثية الأبعاد (Pixar-style) لتعليم الحروف العربية للأطفال الصغار.

- **3 مقاطع × 30 ثانية** (كل مقطع = 3 لقطات × 10 ثوانٍ) = **9 لقطات**.
- عمودي `9:16` — `1080×1920` — `30 FPS` — كاميرا ثابتة 100%.
- الأبطال الثابتون: 👦 **زَيْد** + 🐱 **سِمْسِمْ** في كل الحلقات.
- نطق **عربي فصحى مبسّط ومشكول** + موسيقى أطفال مبهجة ومؤثرات لطيفة.

| المقطع | الحرف | المكان | الكلمات |
|---|---|---|---|
| 01 | **أَ** (الفتحة) | الحديقة المشمسة | أَرْنَبٌ · أَسَدٌ |
| 02 | **أُ** (الضمة) | الشاطئ والبركة | أُخْطُبُوطٌ · أُذُنٌ |
| 03 | **إِ** (الكسرة) | ضفة البحيرة | إِوَزَّةٌ · إِبْرِيقٌ |

## المجلدات
- `00_MEMO/` — مذكرة الإنتاج الكاملة.
- `01_REFERENCES/` — صفحة الشخصيات + مجسّمات الحروف المرجعية.
- `02_SCENES/` — صور اللقطات التسع (`1080×1920`).
- `03_FLOW_PROMPTS/` — برومبتات Google Flow (8 أقسام إلزامية).
- `04_AUDIO/` — التعليق الصوتي المشكول لكل مقطع (MP3).
- `05_MUSIC/` — موسيقى أطفال مبهجة 30 ثانية لكل مقطع (WAV، بدون حقوق).
